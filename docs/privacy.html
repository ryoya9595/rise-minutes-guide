このポリシーについて

「RISE議事録メーカー」（以下「本ツール」）は、RISE（ラッキーマインAIスクール）の講師が、面談の録画から議事録を作るための運営向けツールです。本ツールがどの情報をどう扱うかを、このページで説明します。

運営者：RISE運営事務局（株式会社ECHOOZ）／連絡先：ryoyatennis95s@gmail.com

本ツールが取得する情報

本ツールは、利用者（講師）がGoogleアカウントで許可した範囲で、次の情報にアクセスします。

  • YouTube（スコープ：https://www.googleapis.com/auth/youtube.force-ssl）
    利用者自身がアップロードした面談録画について、動画のタイトル・アップロード時のファイル名・自動字幕（文字起こし）を読み取ります。また、議事録の作成後に、その動画のタイトルを「【RISE面談】〇〇様 日付 講師名」の形式に変更します。利用者の動画を公開したり、削除したり、他の動画を操作したりすることはありません。
  • Googleカレンダー（読み取りのみ）
    Lステップから連携された面談予約を読み取り、受講生の名前と担当講師を自動で入力するために使います。予定の作成・変更はしません。
  • Googleアカウントのメールアドレス
    利用登録済みの講師かどうかを確認するために使います。

情報の使いみち

  • 読み取った字幕（文字起こし）は、議事録を生成するためにGoogleの生成AI（Gemini API）へ送信します。生成された議事録は、RISE運営が管理するGoogleドキュメント（受講生ごとの議事録・顧客サマリー）と運営用の記録シートに保存されます。
  • YouTubeの認証情報（アクセストークン・リフレッシュトークン）は、利用者本人のGoogleアカウントに紐づくApps Scriptのユーザープロパティに保存され、他の利用者や運営から参照されることはありません。
  • 取得した情報を広告目的で使うこと、第三者へ販売・提供することはありません。

本ツールによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

保存期間と削除

  • YouTubeの認証情報は、利用者がツール内の「YouTubeチャンネル連携」で「外す」を押すか、Googleアカウントの「サードパーティ製のアプリとサービス」から本ツールのアクセス権を削除した時点で無効になります。
  • 字幕（文字起こし）は議事録の生成にのみ使い、本ツール側には保存しません。
  • 生成した議事録は、RISEの受講生サポートのために運営が保管します。削除のご希望は上記の連絡先までお知らせください。

変更について

本ポリシーを変更する場合は、このページで公開します。
