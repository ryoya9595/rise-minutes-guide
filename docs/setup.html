RISE議事録メーカー はじめの設定

▶ 解説動画はこちら

使い始める前に、1回だけやることだけをまとめました。全部で5〜10分です。

いちばん簡単な方法：ツールの「設定チェック」に任せる

運営から届いたツールのURLを開くと、🔰 はじめての設定チェックが自動で出ます。ツールがあなたの設定を確認して、✅ か ❌ で教えてくれます。

  1. ツールのURLを開く（はじめての時は許可画面が出るので、「詳細」→「（安全ではないページ）に移動」→「すべて選択」→「続行」）
  2. 設定チェックの ①② を見る。❌ が出たら、その下に出ている直し方のとおりに進める（あなたの状況に合った手順だけが出ます）
  3. ③ に、アップ済みの面談録画のURLを1本貼って「テストする」
  4. 全部 ✅ になれば設定完了です
このページの下の説明は、設定チェックの内容を詳しく書いたものです。チェックで ✅ がそろった人は読まなくて大丈夫です。

（詳しく知りたい人向け）自分がどれに当てはまるか

質問1：面談の録画は、どのYouTubeチャンネルにアップしていますか？

  • 運営が用意したチャンネル（RISE管理用など、権限をもらってアップしている）→ パターンA
  • 自分のYouTubeチャンネル → 質問2へ

質問2：そのYouTubeのGoogleアカウントは、Lステップの予約と連携しているGoogleアカウントと同じですか？

  • 同じ → パターンA
  • 違う（または分からない）→ パターンB
「Lステップと連携しているアカウント」＝ 自分の面談予約が入ると、予定が自動で入るGoogleカレンダーのアカウントです。分からないときは運営に聞いてください。

パターンA：許可するだけ（3分）

運営のチャンネルにアップしている人／自分のチャンネルで、YouTubeとLステップ連携が同じアカウントの人

  1. 運営から届いたツールのURLを開く（パソコン推奨）
  2. 開くときのGoogleアカウントはLステップと連携しているアカウント（運営のチャンネルにアップしている人）、または自分のチャンネルのアカウント
  3. 「権限を確認（REVIEW PERMISSIONS）」→ アカウントを選ぶ → 「詳細」→「（安全ではないページ）に移動」
  4. 「すべて選択」にチェックを入れて「続行」
  5. 動画のURLを1本読み込んでみて、クライアント名の下に「Lステップの予約から自動で入れました」と出れば完了
「すべて選択」を押さないと、名前や面談日が自動で入りません。チェックが1つでも外れていたら戻ってやり直してください。

パターンB：許可＋2つの連絡・設定（10分）

自分のチャンネルにアップしていて、YouTubeのアカウントとLステップ連携のアカウントが違う人

B-1. 使うアカウントを運営に伝える

受講生の情報を扱うため、登録されたアカウントだけが使えます。次の文をコピーして運営に送ってください。

RISE議事録メーカーの利用登録をお願いします。 ・講師名： ・ツールを開くGoogleアカウント（YouTubeに面談をアップしているアカウント）： ・Lステップの予約と連携しているGoogleアカウント：

B-2. カレンダーを、自分のYouTube用アカウントに共有する

これをやると、受講生の名前と担当講師が自動で入ります。共有先は自分のもう1つのアカウントなので、他の講師や運営に予定が見えることはありません。

  1. Lステップと連携しているアカウントでパソコンから Googleカレンダー を開く
  2. 左の「マイカレンダー」で、予約が入るカレンダー（ふつうは自分の名前のカレンダー）にマウスを乗せて「︙」→「設定と共有」
  3. 「特定のユーザーまたはグループと共有する」→「ユーザーやグループを追加」
  4. 自分のYouTube用Googleアカウントのアドレスを入力（他の人のアドレスと間違えないように）
  5. 権限を「予定の表示（すべての予定の詳細）」にして「送信」
  6. YouTube用アカウントのGmailに届くお知らせで「このカレンダーを追加」を押す
Lステップの設定は何も変わりません。予約の受付にも影響しません。

B-3. ツールを開いて許可する

  1. 運営から届いたツールのURLを、YouTube用アカウントで開く
  2. 「権限を確認」→ アカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」
  3. 「すべて選択」にチェックを入れて「続行」
  4. 動画のURLを1本読み込んで、「Lステップの予約から自動で入れました」と出れば完了

つまずきやすいところ

  • 「現在、ファイルを開くことができません」と出る
    ブラウザに複数のGoogleアカウントでログインしているときに出ます。シークレットウィンドウを開いて、使うアカウントだけでログインしてからツールのURLを開いてください。
  • 「このGoogleアカウントはまだ利用登録されていません」と出る
    画面に出ているアドレスを運営に伝えてください（B-1の文が使えます）。
  • クライアント名の下に「カレンダーが見えません」と出る
    B-2のカレンダー共有がまだです。共有してから、もう一度「読み込む」を押してください。
  • チャンネルを選ぶ画面が出た
    面談録画をアップしているチャンネルを選んでください。

設定できたか、最後のチェック

  • ツールのURLを開いて、エラーが出ずに画面が表示される
  • 面談録画のURLを貼って「読み込む」を押すと「字幕あり」と出る
  • クライアント名の下に「Lステップの予約から自動で入れました」と出る
  • 面談日の下に「Zoomの録画ファイルから自動で入れました」と出る
  • 担当講師に自分の名前が入っている
5つそろえば設定は完了です。あとは毎回、URLを貼って「議事録を作って書き込む」を押すだけになります。

※ 面談日が「⚠️ 面談日を入れてください」になる場合は、Zoomの録画ファイルの名前を変えてアップしています。次回からファイル名を変えずにアップすると自動で入ります。

使い方の詳細は 講師向けガイド を見てください。

AIエージェントに手伝ってもらう

設定でつまずいたら、Claude CodeなどのAIエージェントに次の文を渡してください。

このページを読んで、RISE議事録メーカーの初期設定を一緒に進めてください。 https://ryoya9595.github.io/rise-minutes-guide/setup.html 私がどのパターンに当てはまるかを質問で確かめてから、1ステップずつ案内してください。 パスワードは扱わないでください。Googleの許可ボタンは私が押します。

（AIエージェントの方へ：まず「録画のアップ先」と「2つのGoogleアカウントが同じか」を質問して、パターンAかBかを判定してください。Bの場合は B-1 の連絡文を用意し、B-2 のカレンダー共有を1ステップずつ案内し、最後に「設定できたか、最後のチェック」の5項目を一緒に確認してください。利用者のパスワードやAPIキーを扱わず、許可ボタンは本人に押してもらってください。）
